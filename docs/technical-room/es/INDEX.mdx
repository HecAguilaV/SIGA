# 🌌 SIGA Technical Room

Bienvenido al **Centro de Mando Arquitectónico** de SIGA. Este espacio utiliza el estándar **4+1 View Model** de Philippe Kruchten para proporcionar una visión holística, técnica y educativa del sistema.

[🇺🇸 View English Version](../en/INDEX.mdx)

## 📐 El Modelo 4+1

Este modelo nos permite describir la arquitectura basándonos en el uso de múltiples vistas concurrentes, cada una dirigida a un "stakeholder" diferente:

### [01. Vista de Escenarios (+1)](./01-SCENARIOS.mdx)
*   **Para quién**: Usuarios finales y analistas.
*   **Qué muestra**: Casos de uso críticos que validan la arquitectura.

### [02. Vista Lógica](./02-LOGICAL-VIEW.mdx)
*   **Para quién**: Desarrolladores y arquitectos.
*   **Qué muestra**: El Modelo Entidad-Relación y la Arquitectura Hexagonal.

### [03. Vista de Desarrollo](./03-DEVELOPMENT-VIEW.mdx)
*   **Para quién**: Ingenieros de software y DevOps.
*   **Qué muestra**: Estructura del monorepo, stack tecnológico y flujo de CI/CD.

### [04. Vista de Proceso](./04-PROCESS-VIEW.mdx)
*   **Para quién**: Integradores de sistemas.
*   **Qué muestra**: Diagramas de secuencia y estados transaccionales (SAGA).

### [05. Vista Física](./05-PHYSICAL-VIEW.mdx)
*   **Para quién**: Administradores de sistemas y Cloud Engineers.
*   **Qué muestra**: Despliegue en Docker, escalabilidad Big Data y arquitectura Lambda.
