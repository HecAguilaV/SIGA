## 📐 The 4+1 Model

This model allows us to describe the architecture based on the use of multiple concurrent views, each directed at a different stakeholder:

### [01. Scenarios View (+1)](./01-SCENARIOS.mdx)
*   **Target Audience**: End users and analysts.
*   **Key Insight**: Critical use cases that validate the architecture.

### [02. Logical View](./02-LOGICAL-VIEW.mdx)
*   **Target Audience**: Developers and architects.
*   **Key Insight**: Entity-Relationship Model and Hexagonal Architecture.

### [03. Development View](./03-DEVELOPMENT-VIEW.mdx)
*   **Target Audience**: Software engineers and DevOps.
*   **Key Insight**: Monorepo structure, tech stack, and CI/CD workflow.

### 04. Process View (Coming Soon)
*   **Target Audience**: System integrators.
*   **Key Insight**: Sequence diagrams and transactional states (SAGA).

### 05. Physical View (Coming Soon)
*   **Target Audience**: System administrators and Cloud Engineers.
*   **Key Insight**: Docker deployment, Big Data scalability, and Lambda architecture.
